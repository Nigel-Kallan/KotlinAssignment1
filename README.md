# KotlinAssignment1

## MWD3B - Android Development
**Assignment 1**

This project demonstrates fundamental Kotlin programming concepts covered in the Kotlin Apprentice textbook and course material.

## Code Challenges

### A. Sum of Integers
Creates a function that adds all integers starting at 1 up to a specified maximum.

Example:

1 + 2 + 3 + ... + 10 = 55

### B. Iterative Factorial
Creates an iterative function using a loop to calculate the factorial of a specified integer.

Example:

5! = 5 × 4 × 3 × 2 × 1 = 120

### C. Factorial Using a Lambda
Rewrites the iterative factorial calculation using a Kotlin lambda expression.

Example:

5! = 120

### D. Recursive Factorial
Creates a recursive function that calculates a factorial by calling itself until the base case is reached.

Example:

5! = 120
